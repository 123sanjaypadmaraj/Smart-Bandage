# E. coli EIS dataset (graphene-PBASE-aptamer electrode)

Synthetic, generated by `python scripts/generate_eis_dataset.py` (deterministic; code in
`digital_twin/bandage/eis_dataset.py`). Parameters are illustrative, not bench-fitted.

- `runs.csv` — one row per assay (84): class, CFU/mL, train/test split, true and fitted Randles
  parameters (Rs, Rct, Cdl, sigma, n) before/after exposure, |Z| and phase at 100 Hz,
  dZ / dRct / dCdl / dRs / dsigma, and the detection call.
- `spectra.csv` — raw measured points, long format: `run_id, phase (baseline|post), freq_hz, re, im, mag, phase_deg`
  (61 points, 0.1 Hz – 100 kHz, 10 per decade, 1 % noise).

| class | what | runs |
|---|---|---|
| `target` | E. coli, 1e1 – 1e7 CFU/mL | 7 levels x 8 |
| `blank` | PBS, negative control | 16 |
| `nonspecific` | S. aureus, 1e3 / 1e5 / 1e7 (weak adsorption) | 3 levels x 4 |

Every electrode has its own lot spread, a small non-binding Rct drift, and a random contact time
(300 – 1800 s). Replayed as hardware output by `backend/app/hardware_eis.py`
(`GET /api/hardware/eis/capture`, `WS /ws/hardware/eis`).
